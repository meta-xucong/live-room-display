# MCP 排班填写示例

把这份文档和真实排班一起发给已连接「直播间排班助手」的 WorkBuddy 或 Codex。排班可以直接粘贴，也可以附上文件。看完预览后回复「确认提交」。

## 复制到会话

```text
请用「直播间排班助手」处理我随这条消息发来的真实排班。下方例子只用于参考格式。还没收到真实排班时，请让我补发。

1. 先核对直播间名称和编号，逐日整理导演、主播、助播三份班次。三种岗位都按自己的起止时间录入。主播场次的商品、目标销售额和备注照原文填写。
2. 单日用 preview_schedule_update，同一直播间多日用 preview_room_schedules_update。助播放在独立的 assistantShifts 列表里。如果我明确写「无助播」，预览中将助播列表设为空。如果我写「助播沿用」，保留当天的助播班次。
3. 日期、直播间、姓名、起止时间或某类当天的完整排班不清楚时，先向我核实。我明确说某类「沿用」时，可读取当天安排并照录原班次。结束在次日的班次以开始日期归档。
4. 按直播间和日期展示预览，分开列出三种岗位的姓名、时段、替换数量和校验提示。等我回复「确认提交」后再写入。

填写示例（以下为示意数据）

01 号直播间，2026-12-01
导演 07:00–13:00 吴丹，13:00–18:00 赵岚
主播 08:00–12:00 张思琪，主推经典学长、经典老爹，目标 8 万
主播 12:00–16:00 王晓，主推羽绒服新款，目标 6 万
助播 09:00–10:30 彭欣琦，10:30–13:00 李佳

同一直播间，2026-12-02
导演 08:00–14:00 吴丹
主播 09:00–13:00 张思琪
无助播
```

连接说明见 [MCP 连接器文档](./mcp-connectors.md)。
