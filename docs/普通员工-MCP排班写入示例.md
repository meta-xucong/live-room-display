# 普通员工通过 MCP 添加或更新排班

本文适用于已经安装并连接“直播间排班助手”的 Codex、WorkBuddy 等 Harness。员工只需按模板写自然语言，助手负责调用 MCP 工具；不需要填写 API 地址、密钥或代码。

## 可直接复制的文案模板

将方括号中的内容替换成真实信息。一次请求只处理一个直播间。单日更新按下面模板填写；同一直播间要更新多个日期时，重复日期标题和当天全部时段，助手会一次预览这些日期。

~~~text
请使用已连接的“直播间排班助手”整理并更新排班。

如果我提供了直播间编号，请先用 list_rooms 核对编号和名称。编号不清楚时先问我，不要猜。
以下是指定直播间一个或多个日期的完整排班。每个日期都要按时段顺序列出当天全部时段，不要遗漏。
先生成预览，不要提交。预览时请逐日说明将替换多少个现有时段、完整列出排班，并提醒我处理所有校验错误和头像缺失提示。
信息不完整或时段有冲突时先问我。只有我明确确认预览后才能提交。

直播间编号：[例如 01]
直播间名称：[现有直播间可不填；新直播间必填]
排班日期：[YYYY-MM-DD]
---
时段：[开始时间-结束时间，例如 07:00-11:00]
导演：[姓名；没有则留空]
主播：[姓名]
助播：[姓名；没有则留空]
主推商品：[商品一；商品二；商品三；没有则留空]
目标销售额：[例如 6万、200000；没有则留空]
备注：[没有则留空]
---
时段：[当天下一时段；没有则删掉本段]
导演：
主播：
助播：
主推商品：
目标销售额：
备注：
~~~

当天有几个时段就保留几个“时段”区块，按时间顺序填写。导演、主播、助播、主推商品、目标销售额和备注没有内容时可以留空；开始时间、结束时间必须填写。

同一个直播间需要更新多个日期时，在上一日期的时段区块后继续添加下一日期及其全部时段，例如：

~~~text
排班日期：2026-11-17
---
时段：07:00-12:00
导演：姓名
主播：姓名
助播：
主推商品：商品一
目标销售额：5万
备注：

排班日期：2026-11-18
---
时段：08:00-12:00
导演：姓名
主播：姓名
助播：
主推商品：商品二
目标销售额：6万
备注：
~~~

不要把不同直播间放在同一个 MCP 更新请求中；未列出的日期和其他直播间不会改变。

## 确认预览后提交

助手展示预览后，请核对直播间编号、日期、当天时段数量、人员、商品、销售目标和警告。确认无误后回复：

~~~text
我确认以上预览。请提交这份直播间当天的完整排班。
~~~

没有明确确认前，助手不应提交。预览后如果排班数据被其他人修改，原预览会失效；需要重新预览并再次确认。

下面仅演示文案结构，人物、商品和销售额是示例数据。

导演：吴丹
主播：王晓
助播：

## 主播姓名和头像

- 排班按主播姓名匹配头像库。姓名会先做 Unicode 规范化、去除空白和忽略大小写处理；系统不会模糊猜测不同姓名。
- 如果有同名主播，可用括号加稳定备注区分，例如“张敏（A组）”和“张敏（B组）”。管理员头像库和排班里都要使用相同写法。括号内容会显示在直播间展示页上。
- MCP 对话里的图片附件不会自动保存为主播头像。新增或更换照片请由管理员在网页“主播头像库”上传，并为照片填写与排班一致的主播姓名。
- 预览可能显示“头像库”“本场已有照片”或“未配置”。缺少头像不会阻止排班提交；管理员补充头像后，所有同名关联排班会自动使用头像库照片。

## 重要规则

- 排班更新会替换指定直播间、指定日期的全部时段，不是只改其中一场。即使只改一个时段，也要把当天其余时段一起写上。一次更新多个日期时，每天都要提供完整时段；没有列出的日期及其他直播间保持不变。
- 日期建议直接写 YYYY-MM-DD，时段使用 24 小时制，例如 13:00-17:00。写“今天/明天”时，助手按上海时区换算并在预览中展示具体日期。
- 商品用分号分隔；目标销售额按时段填写。
- 不确定直播间、日期、人员或排班边界时先补充信息，不要让助手猜测。
