# MCP 排班填写示例

在已连接直播间 MCP 的 Codex 或 WorkBuddy 会话中，复制下面的自然语言指令，再把真实排班粘贴在后面或作为附件发送。无需编写 MCP 参数或 JSON。

```text
请读取我这条消息中粘贴或附上的真实排班，更新苏豪直播展示板。

请遵守：
1. 导演排班和主播排班是两份独立安排，分别按各自的时间录入，不要按行配对。
2. 助播跟随对应主播场次，不需要单独排时间。
3. 只使用我提供的直播间、日期、人员和时间；缺少或有歧义时先问我，不要猜。
4. 更新某个日期时会替换该直播间当天的完整导演与主播排班。请确认两份完整名单；如果某类当天没有排班，我会明确写“无”。
5. 先展示分别列出的导演班次和主播场次预览，并说明将替换哪个直播间、哪一天。等我明确确认后再提交。

以下是我的真实排班：
（在这里粘贴排班，或在同一条消息中附上排班文件）
```

## 自然语言示例

```text
请按上面的规则，更新 01 号直播间（MLB服饰旗舰店）2026-11-18 的完整排班。

导演：07:00-13:00 吴丹；13:00-23:00 赵岚。
主播：
- 07:00-11:00 张思琪，助播彭欣琦，主推经典学长、经典老爹，目标 8 万。
- 11:00-15:00 王晓，无助播，主推羽绒服新款，目标 6 万。
- 15:00-19:00 张思琪，助播彭欣琦，主推经典学长，目标 6 万。
- 19:00-23:00 王晓，无助播，主推羽绒服新款，目标 6 万。

请先预览，等我确认后再写入。
```

示例中是 **2 个导演班次、4 个主播场次**。同一角色的排班不能重叠；导演和主播之间可以错时或交叉。主播照片请由管理员在网页“主播头像库”维护，系统会按主播姓名匹配。

更多连接说明见 [MCP 连接器文档](./mcp-connectors.md)。
