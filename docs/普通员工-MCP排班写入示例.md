# 普通员工通过 MCP 写入排班示例

> 本文用于指导已安装并连接“直播间排班助手”的员工。示例只用于演示填写方式，不会自动写入系统；示例中的人员、商品和销售额请按真实安排替换。

## 当前时间示例

本示例以 **2026 年 11 月 16 日 16:55（上海时间）** 为例。此时处于 13:00–17:00 时段；到 17:00 后，展示页会自动切换到 17:00–23:00 时段。

MCP 提交会替换指定直播间当天的完整排班，因此需要列出当天全部时段。不要只提供当前正在进行的时段，否则当天其他时段可能被移除。

## 可直接复制到 Codex 或 WorkBuddy 的文案

~~~text

这是该直播间 2026-11-16 当天的完整排班。请保留所有时段，并指出预览中的校验警告。

直播间编号：01
直播间名称：MLB服饰旗舰店
排班日期：2026-11-16
~~~

确认预览内容无误后，员工再回复：

~~~text
我确认这份完整预览，请提交到系统。
~~~

助手随后提交刚才生成的预览。若日期、直播间、人员或时段信息不完整，应先补齐；助手不会自行猜测。

### 填写规则

- 一个请求填写一个直播间、一个日期及该日完整排班。
- 每个时段写清 24 小时制起止时间，例如 **13:00-17:00**。
- 每个时段都保留导演、主播、助播、主推商品、目标销售额和备注字段；没有内容时可留空。
- 商品可用中文分号“；”分隔。
- 目标销售额按时段填写。示例将全天 20 万拆分为 8 万、6 万、6 万，页面会显示当前时段对应的目标。

## 主播头像说明

如果 Codex 或 WorkBuddy 的对话框支持图片附件，员工可以把图片附在对话中。但**当前 MCP 写入工具不接收、保存或关联图片**；头像不会因为发到对话框而写入排班系统。

新增或更换主播头像时，请由管理员在网页的“主播头像库”上传照片，并准确填写主播姓名。排班会按主播姓名自动匹配头像，更新后所有关联直播时段都会使用新头像。

Harness 的 MCP 文本接口不接收图片附件。系统匹配不到头像时，预览会提示管理员补充；原时段且主播未变时仍会保留本场旧照片。
